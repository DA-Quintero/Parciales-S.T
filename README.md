# Primer Parcial — Servicios Telemáticos

Repositorio correspondiente al **Primer Parcial de Servicios Telemáticos**, desarrollado como un microproyecto integrador sobre una infraestructura virtualizada con **Vagrant y VirtualBox**.

El parcial integra los temas de:

- DNS maestro/esclavo con BIND9.
- Transferencia segura de zonas mediante TSIG.
- Resolución DNS directa e inversa.
- Hardening y auditoría del servicio DNS.
- Servidor HTTP Apache.
- Compresión HTTP con `mod_deflate` y `mod_brotli`.
- Medición de tamaño, tiempo y costo de CPU.
- Publicación del servidor web mediante un túnel seguro.
